YouTube Finance Automation Bot — Pipeline AI 8 Bước, $0 Chi Phí, Hoàn Toàn Tự Động

Python · Groq API (LLaMA 3.3 70B) · Microsoft edge-tts · faster-Whisper · FFmpeg · Pillow · YouTube Data API v3

Thách Thức

Sản xuất thủ công 1 video YouTube tài chính chất lượng tốn 40+ giờ: nghiên cứu, script, thu âm, chọn footage, dựng phim, sync phụ đề, thiết kế thumbnail, SEO metadata và upload. Khối lượng này khiến scale kênh gần như bất khả thi với một người.

Giải Pháp

Xây dựng pipeline Python end-to-end nơi AI xử lý mọi bước sản xuất. Con người chỉ cần ~5–10 phút để review cuối. Chi phí tổng: $0 — toàn bộ API đều free tier.

  • Groq API (LLaMA 3.3 70B) tạo script, storyboard và metadata YouTube hoàn chỉnh — title, tags, description, thumbnail text.
  • Pexels API tự động tải HD stock footage cho từng cảnh theo keyword trong storyboard.
  • Microsoft edge-tts chuyển script thành giọng đọc neural tiếng Anh tự nhiên — hoàn toàn miễn phí, không cần API key.
  • faster-Whisper (AI local, chạy CPU) tạo file phụ đề SRT sync tự động từ voiceover — $0, không cần GPU.
  • FFmpeg ghép tất cả tài nguyên thành MP4 hoàn chỉnh: footage + giọng đọc + phụ đề + nhạc nền.
  • Pillow tự động tạo thumbnail YouTube với text gợi ý từ AI, stock photo và brand overlay.
